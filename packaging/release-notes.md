# RE-FIGS v1.0.0

## Windows 下载

- `RE-FIGS-1.0.0-windows-x64-setup.exe`：Windows 64 位安装包，安装到当前用户目录，无需额外安装 Python/Conda。
- `RE-FIGS-1.0.0-windows-x64-portable.zip`：便携版，完整解压后运行文件夹内 RE-FIGS.exe，请勿单独移动 EXE。
- `SHA256SUMS.txt`：下载文件 SHA-256 校验值。

## 更新

- 按文件查看分析状态、耗时与历史日志，改善字体、配色和长文件名显示。
- 支持终止整个批次，协作退出超时后强制结束，关闭窗口时清理计算进程。
- 每个输入文件独立保存结果与 task.log，批次共享数据位于 _shared。
- 支持复用已有预计算 decoy 库，跳过建库。
- 训练目标不足时记录明确失败说明、筛选数量和参数。
- 增加中文使用说明及完整源码安装教程。

## 使用提示

预计算目录需包含配套且可信的 library.npy、csodiaq_library.npy。终止任务可能留下不完整 CSV，请以任务状态和日志为准。签名未配置，安装包未进行代码签名。科学计算结果仍需结合真实数据与实验要求验证。
